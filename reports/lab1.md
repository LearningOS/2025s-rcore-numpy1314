# lab1

### 编程作业
获取任务信息
在 ch3 中，我们的系统已经能够支持多个任务分时轮流运行，我们希望引入一个新的系统调用 ``sys_trace``（ID 为 410）用来追踪当前任务系统调用的历史信息，并做对应的修改。定义如下。

fn sys_trace(_trace_request: usize, _id: usize, _data: usize) -> isize
调用规范：
这个系统调用有三种功能，根据 trace_request 的值不同，执行不同的操作：

如果 trace_request 为 0，则 id 应被视作 *const u8 ，表示读取当前任务 id 地址处一个字节的无符号整数值。此时应忽略 data 参数。返回值为 id 地址处的值。

如果 trace_request 为 1，则 id 应被视作 *mut u8 ，表示写入 data （作为 u8，即只考虑最低位的一个字节）到该用户程序 id 地址处。返回值应为0。

如果 trace_request 为 2，表示查询当前任务调用编号为 id 的系统调用的次数，返回值为这个调用次数。本次调用也计入统计 。

否则，忽略其他参数，返回值为 -1。

### 简要过程
在TCB实现一个调用次数记录数组，观察系统调用号410，暂且将这个数组长度设定为500

之后需要在/src/task/mod.rs做好初始化，将所有调用计数初始化为0

再然后就是按照题目要求实现这个sys_trace函数，注意要用unsafe包裹操作即可（主要是0和1两种request），考虑到涉及调用次数的查询和增长，还要回到task/mod.rs在manager中实现相关对应的函数，并在syscall/mod.rs中每一次需要系统调用的时候进行一次调用次数的增长即可
